API Integration

Use your API key to integrate ContentGuard Pro into your applications:

cURL Example:
curl -X POST "http://localhost:5000/api/v1/analyze" \
  -H "X-API-Key: {{ user.api_key }}" \
  -H "Content-Type: application/json" \
  -d '{"content": "Your content to analyze"}'
Python Example:
import requests

response = requests.post(
    "http://localhost:5000/api/v1/analyze",
    headers={"X-API-Key": "{{ user.api_key }}"},
    json={"content": "Your content to analyze"}
)

result = response.json()
print(f"Decision: {result['analysis']['decision']}")
print(f"Confidence: {result['analysis']['confidence']}")
