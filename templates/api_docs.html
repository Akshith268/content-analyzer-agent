ContentGuard Pro API

Powerful AI-driven content moderation and analysis API

Base URL: http://localhost:5000/api/v1

Features

  • Real-time Analysis: Sub-second content moderation
  • Learning AI: Improves accuracy over time
  • Multi-format: Text, with support for images and video coming soon
  • Scalable: From 100 to unlimited API calls per month

Authentication

All API requests require an API key. Include your API key in the request header:

X-API-Key: your_api_key_here
Security: Never expose your API key in client-side code. Always make requests from your server.

API Endpoints

}

Code Examples

cURL

curl -X POST "http://localhost:5000/api/v1/analyze" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "This is amazing content!"
  }'

Python

import requests

# Your API key from dashboard
api_key = "your_api_key_here"

# Analyze content
response = requests.post(
    "http://localhost:5000/api/v1/analyze",
    headers={"X-API-Key": api_key},
    json={"content": "This is amazing content!"}
)

result = response.json()

if result["success"]:
    analysis = result["analysis"]
    print(f"Decision: {analysis['decision']}")
    print(f"Confidence: {analysis['confidence']:.2%}")
    print(f"Reason: {analysis['reason']}")
else:
    print(f"Error: {result['error']}")

JavaScript (Node.js)

const axios = require('axios');

const apiKey = 'your_api_key_here';

async function analyzeContent(content) {
  try {
    const response = await axios.post(
      'http://localhost:5000/api/v1/analyze',
      { content: content },
      {
        headers: {
          'X-API-Key': apiKey,
          'Content-Type': 'application/json'
        }
      }
    );
    
    const result = response.data;
    
    if (result.success) {
      console.log('Decision:', result.analysis.decision);
      console.log('Confidence:', result.analysis.confidence);
      console.log('Reason:', result.analysis.reason);
    }
  } catch (error) {
    console.error('Error:', error.response?.data || error.message);
  }
}

// Use the function
analyzeContent("This is amazing content!");

Error Handling

HTTP Status Codes

Code Description
200 Success
400 Bad Request - Invalid content or missing parameters
401 Unauthorized - Invalid or missing API key
429 Too Many Requests - Rate limit exceeded
500 Internal Server Error

Error Response Format

{
  "success": false,
  "error": "Invalid API key",
  "error_code": "INVALID_API_KEY"
}
