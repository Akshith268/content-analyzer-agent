API Integration (India Edition)

Integrate ContentGuard Pro into your Indian applications:

cURL Example:
curl -X POST "http://localhost:5000/api/v1/analyze" \
  -H "X-API-Key: {{ user.api_key }}" \
  -H "Content-Type: application/json" \
  -d '{"content": "आपका content यहाँ लिखें"}'
Python Example:
import requests

# Your API key
api_key = "{{ user.api_key }}"

# Analyze content (Hindi/English supported)
response = requests.post(
    "http://localhost:5000/api/v1/analyze",
    headers={"X-API-Key": api_key},
    json={"content": "यह बहुत अच्छा content है!"}
)

result = response.json()
if result["success"]:
    print(f"Decision: {result['analysis']['decision']}")
    print(f"Confidence: {result['analysis']['confidence']:.2%}")
    print(f"Remaining: {result['usage']['remaining']}")
